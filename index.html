Format Specification
FieldDescription
FRD-V1Magic header — identifies a valid FRD file
filenameOriginal image filename with extension
createdUnix timestamp (ms) of conversion
typeMIME type of the original image
width / heightPixel dimensions of the original
qualityCompression quality used (10–100)
encryptedtrue if data is XOR-encrypted with a key, false otherwise
DATA_STARTMarks the beginning of Base64 image data
