What is .imgc?
A lightweight, human-readable custom image container format — no binary, no magic bytes, just structured text.
STEP 01
Pick an image
Drop any PNG, JPG, JPEG, or WEBP file into the encoder.
STEP 02
Pack into .imgc
The browser encodes the image as Base64 and wraps it in a structured text header.
STEP 03
Download & share
Save the .imgc file. It carries all metadata and can be restored later.
STEP 04
Restore anytime
Drop the .imgc into the decoder to extract the original image back out.
